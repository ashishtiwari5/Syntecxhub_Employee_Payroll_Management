# Employee Payroll Management System

## Overview
This project is a Java + MySQL based Employee Payroll Management System developed as part of the Syntecxhub Internship Program.

The system helps manage employee records, calculate payroll, update salaries, and generate payslips using JDBC connectivity.

---

## Technologies Used
- Java
- JDBC
- MySQL
- IntelliJ IDE

---

## Features
- Add Employee
- View Employees
- Update Employee Details
- Delete Employee
- Generate Payslip
- MySQL Database Connectivity

---

## Functionalities

### Add Employee
Stores employee details into MySQL database.

### View Employees
Displays all employee records from database.

### Update Employee
Updates employee name, position, and salary.

### Delete Employee
Removes employee record from database.

### Generate Payslip
Calculates:
- Allowances
- Deductions
- Net Salary

and displays formatted payslip.
